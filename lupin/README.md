# 怪盜 Lupin：世紀大追捕 — QR 手機控制版

以用戶提供的 `Lupin_Control_V1.html` 為基線；檔案內標示為 V6 遊戲規則。

入口：https://angusma0711.github.io/ycmc-last-moon-c5/lupin/

## 課堂操作

1. 電腦／e-board 開啟入口，按「建立課堂及 QR code」。
2. 主控導師用私人手機掃描，按「這是私人手機，連接課堂」。電腦自動切換公開大屏。
3. 手機選 Lupin 起點，依原 V6 流程移動、鎖定位置、處理 A 組查詢及 B 組行動。
4. 手機「複製大屏連結」，或展開頂部「第二間房的大屏連結」，在另一間房電腦開啟同一連結。兩個大屏會同步公開事件、回合、資源及最終結果。
5. A 組精準查詢答案只在手機顯示，由導師按原活動安排轉達；不會自動廣播到兩間房。學生仍透過實體 Walkie-talkie 交流。

第一位導師打開「課堂工具」並按「邀請第二位導師」。另一位導師在自己的手機掃描這個私人 QR，兩人即可操作同一局。首次邀請有效期為 10 分鐘。

## 公開畫面與秘密資料

公開大屏沒有起點／移動選單、秘密地圖標記、控制按鈕、返回主持畫面按鈕或 Esc 返回主持捷徑。

公開 Firebase snapshot 使用明確白名單：回合、公開階段、剩餘查詢／拘捕／防盜／封鎖資源、公開公告、最終結果及更新時間。

兩位導師的手機透過受權限規則保護的私人進度同步位置、查詢及行動紀錄。每次操作同時更新私人進度與公開畫面。版本衝突時，手機載入最新進度並提示導師重新核對。各手機使用原配對瀏覽器恢復。舊版進行中的課堂請由原主持手機先連接，以匯入該機的秘密進度。

## 斷線

兩端均需連網，且主控手機須保持頁面開啟。手機離線時鎖定遊戲操作，但可匯出本機備份；大屏保留最後的公開資訊。重連後恢復操作，已使用的查詢／行動限制不會被重新開放。

## 保留的 V6 規則

六區路線、每輪合法移動、三次查詢、兩次拘捕、唯一煙幕、C 區防盜、A/F 出口封鎖、盜寶／逃脫及四輪勝負判定均沿用原稿。匯出／匯入格式 `LUPIN_V6_V1` 亦保留。

原稿的公開展示改為真正的獨立大屏頁面。最終勝負會同步顯示在大屏；秘密操作紀錄保持只在手機。

## 部署與測試

靜態頁面位於 `eboard/`。使用既有 Firebase project `ycmc-last-moon-c5`，新增獨立 `lupinRooms` 和 `lupinPairings` 節點；保留午夜十三號及其他既有 namespace。

在既有 GitHub Pages repository 中，本頁發布至 `eboard/lupin/`，不取代原入口。

```sh
node --test tests/*.test.cjs
python3 -m http.server 8794 --directory eboard
node tests/firebase-live.cjs
node tests/browser.cjs
```

Browser QA 使用 Playwright 和 Chrome，`PLAYWRIGHT_MODULE` 可指向已安裝的套件；`LUPIN_URL` 可切換本機／線上入口。測試只建立及清理自己的隨機課堂與匿名帳號。
