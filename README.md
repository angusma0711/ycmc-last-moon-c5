# 午夜十三號：被遺忘的住客

P4–P6 · 8–11 人 · 60 分鐘 · 合作解謎。取代原「最後的月夜」公開入口，沿用原 GitHub Pages 網址：

https://angusma0711.github.io/ycmc-last-moon-c5/

## 課堂使用

1. 電腦開啟入口，按「建立課堂及配對 QR code」。
2. 導師以私人手機掃描 QR，按「連接課堂」。QR 入口 10 分鐘有效，首次配對後只允許同一手機瀏覽器恢復。
3. 電腦會自動切換至遊戲大屏。大屏點一次「啟用課堂聲音」，之後所有聲音、音量、靜音及跳過由手機控制。這一次點擊是瀏覽器播放聲音的要求。
4. 人數、跳幕、提示、計時、第一／二幕通過、結局和重設都在手機。大屏沒有導師設定面板，也沒有 T/H/M 導師捷徑。
5. 第三幕保留學生直接操作的解謎控制台；導師也可在手機代學生輸入。學生只能提交第三幕解謎操作，不能跳幕、調音量或看導師答案。
6. 手機重新整理後按「連接課堂」可恢復同一房間及進度。請保留原手機瀏覽器的登入資料。

## 全程背景音樂

大屏啟用課堂聲音後，原創的低音 drone＋音樂盒懸疑配樂會在序幕至結局持續循環。預設背景音量 30%，另受全局音量控制；導師手機「背景音樂」區可獨立開關及調節。跳幕或暫停計時不會打斷配樂，播放粵語對白或 Jump Scare 時自動降至背景音量的 15%，結束後恢復。全局靜音會同時靜音配樂。

配樂在瀏覽器本機生成，32 秒無縫循環，無需串流、額外音樂服務或下載音樂檔。

## 第二幕粵語 Jump Scare

- 約 0–3 秒：沙沙字幕。
- 約 3 秒：照片出現，播放「你哋係咪唔記得咗我呀？」。
- 約 6.5 秒：播放「時間唔啱……你哋記錯咗……」。
- 約 10.5 秒：返回第二幕，提示翻開照片二。
- 導師可隨時按「立即跳過／解鎖照片」；音訊會停止。全局靜音也會即時停止音訊。
- 使用 macOS 已安裝的 Sinji `zh_HK` 合成香港粵語，附帶 WAV 檔，無需在課堂即時呼叫配音服務。合成聲線，不是真人錄音。
- 手機的「單句播放／課前試音」可逐句在大屏試音。課堂開始前先預告聲效，並提供不觀看的選擇。

## 連線和權限

沿用 Firebase project `ycmc-last-moon-c5`。此遊戲使用獨立的 `midnightRooms` / `midnightPairings` 節點，舊遊戲規則保留。

- 大屏只讀公開狀態。每個房間有 128-bit 隨機網址。
- 導師手機的 Firebase Anonymous Auth UID 是唯一房間擁有者。
- 公開狀態不含配對密鑰或導師答案。學生端提交操作到自己的 inbox，由手機核對幕次及 gameId，再發布新狀態。
- 未配對手機不能搶用已配對的 QR。大屏不能寫入導師狀態。
- 兩台裝置均需連網；手機離線時不接受新操作。斷線大屏會提示並保留畫面，計時依同步截止時間繼續顯示。保持手機頁面開啟，避免手機鎖屏中斷第三幕輸入處理。
- GitHub Pages 只發布 `eboard/`。導師手冊及答案不放在此發布目錄。

## 開發和驗證

```sh
node --test tests/*.test.cjs
python3 -m http.server 8787 --directory eboard
node tests/firebase-live.cjs
node tests/browser.cjs
```

Browser test 使用 Playwright 及本機 Chrome；live tests 建立隨機測試帳號和房間，結束時只清理自己的測試資料。

## 發布

推送 `main` 後，GitHub Actions 先測試，再部署 `eboard/` 至 GitHub Pages。新的 `sw.js` 會取代舊遊戲的 Service Worker，清理其快取。

Firebase 規則以 `firebase deploy --only database --project ycmc-last-moon-c5` 部署。Firebase Hosting 備用入口未包含在此 GitHub Pages 更新範圍內。
